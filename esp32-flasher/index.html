Справка

Как получить .bin из Arduino IDE
  1. Откройте скетч, выберите плату ESP32 Dev Module.
  2. Меню Sketch → Export Compiled Binary (Скетч → Экспорт бинарного файла), или Ctrl+Alt+S.
  3. Меню Sketch → Show Sketch Folder, откройте build/esp32.esp32.esp32/.
  4. Возьмите файл имя_скетча.ino.merged.bin. Это полная прошивка, она пишется по адресу 0x0.
Если плата не подключается
  • Кабель должен передавать данные, а не только заряжать.
  • Закройте Arduino IDE и другие программы, которые держат порт открытым.
  • Ручной режим загрузки: зажмите BOOT, коротко нажмите RST, отпустите BOOT и нажмите «Прошить» ещё раз.
  • Если запись обрывается, уменьшите скорость до 115 200.
  • Windows не видит порт: установите драйвер USB-UART (CH34x или CP210x, в зависимости от чипа).
