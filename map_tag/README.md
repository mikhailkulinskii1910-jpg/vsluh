# Map Tag

Прятки на реальной карте: прячущиеся против охотников. Веб-версия и APK для Android.

- Веб: `…/vsluh/map_tag/` (GitHub Pages). Можно добавить на экран «Домой».
- APK: [`map-tag.apk`](map-tag.apk). Установка: скачать на телефон → открыть → разрешить установку из этого источника.

## Что есть
- Создание игры: код лобби, «Поделиться», QR; размер, видимость, освещение, режим (обучающая / простая / всё и сразу); итог — радиус, время охоты, время на прятки, сужение до 70 %.
- Место и игроки: центр зоны на карте, боты, число охотников, своя роль, перемещение по GPS или касанием (демо).
- Игра: сужающаяся зона, «Раскрытие» (красные круги), «Заморозка» (предупреждение → таймер), «Поймал», выносливость и следы при беге, задания (жёлтые круги, провал — все прячущиеся видны 1 мин), тайники и 12 бонусов, оповещения.
- Профиль: дистанция, игры, время, «Вы в деле», кольцо «охота / прятки», повторы с треком на карте, опрос «Как узнали».
- Правила в 9 шагов, «Что нового», настройки (русский / английский, расширенная настройка игры, разрешения, сброс обучения).

## Версия 1.1
- **Темы из krisa** (Настройки → Тема): Стандарт, Терминал (цвет, свой цвет, RGB-перелив, «Матрица»), Призма (сдвиг радуги), Тепловизор (10 палитр), Чертёж (оттенок и светлота). Перекрашиваются и интерфейс, и карта.
- **Своя территория**: в шаге «Место и игроки» → «Своя территория», касаниями ставятся углы многоугольника; зона сужается к центру.
- **Колесо «Кто водит?»** в лобби.
- **Секретная вкладка «Читы»**: 5 быстрых касаний по логотипу Map Tag → пароль. Внутри — 10 читов для игр с ботами и колесо рандома с подкруткой (подкрутка действует и на колесо в лобби). Пароль хранится только в виде SHA-256.

## Ограничения
Онлайн-сервера пока нет: игра идёт на одном телефоне, остальных игроков изображают боты. «Присоединиться» по коду работает только для лобби на этом же телефоне.

## Сборка APK
```
cd map_tag/android && ./gradlew assembleRelease   # нужен Android SDK (sdk.dir в local.properties или ANDROID_HOME)
```
Веб-файлы из `map_tag/` копируются в `assets/www` при сборке. Подпись — ключ `maptag.jks` (пароль `maptag`), чтобы новые версии ставились поверх старых.
GitHub Actions (`.github/workflows/map_tag.yml`) собирает APK при каждом изменении в `map_tag/`.
