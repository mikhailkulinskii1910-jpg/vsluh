# Шаблон «Своя игра» (igrunok)

Заготовка интерактивной «Своей игры» для урока — по образцу игры «Недоросль».
Один HTML-файл: табло 5 тем × 10 вопросов (10–100 баллов), «Кот в мешке», вопрос на 1000 баллов
с заданиями на «+», таймер, счёт до 6 команд (правится вручную), переименование команд,
звуки, занавес, гравюрные иллюстрации, офлайн-озвучка нейросетевым голосом (выключена при запуске),
подпись автора в итогах и «K.M.» в углу.

## Файлы
- `template.html` — игра-образец (данные «Недоросля»), озвучка пустая (`const VOICE={}`).
- `tools/voice.py` — записать озвучку (Piper «Ирина», офлайн) и встроить в HTML; `--check слова` — проверить ударения.
- `tools/voice_texts.js` — список озвучиваемых фраз (вызывается из voice.py).
- `tools/mkoffline.py` — собрать файл для компьютера со встроенными шрифтами.
- `tools/smoke.js` — проверить экраны, ошибки и покрытие озвучки, сделать скриншоты.
- `tools/skachat.template.html` — страница скачивания (подставить `{{TITLE}}`, `{{TITLE_UPPER}}`, `{{GRADE}}`, `{{FILE}}`, `{{ZIP}}`).
- `pron.example.json` — пример правок произношения.

## Что менять в template.html
| Блок | Что это |
|---|---|
| `<title>`, `#introTitle` (буквы `"НЕДОРОСЛЬ"` в скрипте), тексты заставки, `.brand b` на табло | название игры |
| `const THEMES` | 5 тем: `name`, `art` (ключ иллюстрации), `q`: 10 вопросов `{q,a,n}`; `{cat:true}` — «Кот в мешке» |
| `const CATS` | 5 вопросов «Кота в мешке» (`q`, `eq` — формула или убрать, `a`, `n`) |
| `const FINAL`, `const FINAL_PLUS` | вопрос на 1000 баллов (`say` — текст для озвучки) и задания на «+» |
| `const ART` (`portrait`, `lady`, `school`, `words`, `stage`, `cat`, `gold`) | SVG-иллюстрации тем — перерисовать под новую тему |
| `.sig img` в итогах | подпись автора (PNG с прозрачным фоном в base64) |

## Порядок сборки
```
cp template.html game.html            # заполнить данные и иллюстрации
python3 tools/voice.py --check Имя1 Имя2   # проверить ударения, при ошибках — pron.json
python3 tools/voice.py game.html --pron pron.json
python3 tools/mkoffline.py game.html Игра.html
node tools/smoke.js Игра.html shots
```
