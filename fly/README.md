# Муха на коннектоме (3D-симуляция)

Веб-приложение: муха летает в 3D-арене, ест еду, голодает и возрождается.
Её нейронная сеть — подсеть из 2000 нейронов и 106 тысяч связей, взятая из
открытого коннектома взрослой мухи дрозофилы FlyWire.

## Запуск

Страница загружает данные через `fetch`, поэтому её нужно открыть через веб-сервер.
После правок шаблона или ядра пересоберите страницу: `python3 fly/tools/build_page.py`.


    cd fly
    python3 -m http.server 8000

и открыть http://localhost:8000. На GitHub Pages работает напрямую.

## Что показывает страница

- **Сцена**: сад 10×10 с камнями, стеблями растений, фруктами (яблоко, банан, виноград)
  и колонией мух (1–12, по умолчанию 6). Тени, небо, смена дня и ночи, ветер.
  Светлые частицы показывают запах фруктов, который сносит ветер.
  Камера следит за выбранной мухой или показывает весь сад.
- **Мозг**: 2000 нейронов выбранной мухи в их реальных координатах и активность по группам.
- **Эволюция**: подбор генома в фоновом потоке, график и проверка на фиксированных мирах.
- **Статистика**: выбранная муха, вся колония, графики активности и энергии.
- Переключатель проводки: настоящий коннектом или **контроль** (цели синапсов перемешаны).
- Переключатель **врождённых рефлексов**: можно сравнить муху только на коннектоме и муху
  с рефлексами поиска еды.

## Как устроена модель

**Из коннектома (подсеть FlyWire):**
- обонятельные нейроны слева и справа получают запах в точке каждой антенны;
- механосенсорные — близость стен, камней, стеблей и поток воздуха от стрекозы;
- активность левых и правых моторных нейронов задаёт скорость полёта и поворот;
  накопленный поворот превращается в саккаду — резкий разворот, как у настоящей мухи;
- веса: число синапсов (до 20) × коэффициент; знак по нейромедиатору (GABA и глутамат тормозят);
- динамика: упрощённая модель «интеграции и выстрела» (LIF).

**Правилами, по данным о поведении дрозофилы** (этих цепей в подсети нет):
- запах фрукта — шлейф, который ветер сносит и размывает;
- рефлексы поиска еды (отключаемые): поворот к антенне, где запах сильнее;
  полёт против ветра по шлейфу; прочёсывание поперёк ветра, когда шлейф потерян;
  подлёт по зрению к фрукту на последних сантиметрах;
- посадка на фрукт и еда: фрукт убывает и вырастает заново через ~14 с;
- рефлекс бегства от стрекозы (у мухи за это отвечают гигантские волокна);
- суточный ритм: ночью мухи садятся и спят;
- высота полёта;
- стрекоза охотится только на летящих мух поблизости, после поимки какое-то время сыта.

Без рефлексов, только на коннектоме, мухи в проверке почти не находили еду.
Это ожидаемо: подсеть не содержит цепей навигации по запаху.

## Файлы

- `index.html` — собранная страница. Не правьте её вручную: она собирается
  командой `python3 fly/tools/build_page.py` из `page.template.html` и модулей ядра.
- `page.template.html` — шаблон страницы (Three.js 0.147.0 с jsDelivr, обычные скрипты).
- `sim.js`, `genome.js`, `evolution.js` — ядро симуляции и эволюции (ES-модули для Node;
  на странице встраиваются как обычный скрипт, воркер эволюции создаётся из Blob).
- `data/fly_network.json` — подсеть (2000 нейронов, 106022 связей).
- `tools/build_network.py` — построение подсети из исходных файлов FlyWire.
- `tools/check_sim.mjs` — проверка симуляции без браузера: `node fly/tools/check_sim.mjs 180`.

## Источники данных

- Связи: FlyWire Whole-brain Connectome Connectivity Data, Zenodo 10676866
  (файл `proofread_connections_783.feather`).
- Аннотации (координаты сом, тип клетки, нейромедиатор): flyconnectome/flywire_annotations
  v3.2.0, Zenodo 23037340 (`Supplemental_file1_neuron_annotations.tsv`).
