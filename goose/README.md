# Гусь — Desktop Goose для МОС и досок МОСТЕХ

Переработка Desktop Goose (изначально только для Windows) под Linux: МОС на интерактивных панелях МОСТЕХ / MocTec и любые другие дистрибутивы с X11.
Один файл на Python + PyQt5. Гусь нарисован кодом, а гогот синтезируется при запуске, поэтому оригинальные картинки и звуки не нужны.

Что умеет гусь:

- гуляет по экрану и время от времени гогочет «ГА-ГА!» (вслух через `paplay`/`pw-play`/`aplay`);
- оставляет грязные следы, которые через 14 секунд исчезают;
- хватает курсор и утаскивает его в сторону;
- уходит за край экрана и пятясь притаскивает оттуда заметку или мем. Их можно двигать мышью или пальцем и закрывать крестиком;
- его можно схватить и перенести мышью или пальцем;
- клик правой кнопкой по гусю или по значку в трее открывает меню: пауза, выключатели всех проказ, «Прогнать гуся».

## Установка

```sh
cd goose
sh install.sh              # в меню появится «Гусь»
sh install.sh --autostart  # гусь будет выходить при каждом входе в систему
sh install.sh --remove     # удалить
```

Права root не нужны: всё ставится в `~/.local`. Если PyQt5 нет, скрипт попробует поставить `python3-qt5` через `dnf`, а если не получится, то через `pip install --user PyQt5`.

Запуск без установки: `python3 desktop_goose.py`.

## Управление

| Команда | Что делает |
|---|---|
| `desktop-goose` | выпустить гуся |
| `desktop-goose --quit` | прогнать гуся |
| `desktop-goose --scale 1.5` | гусь крупнее (запоминается) |
| `desktop-goose --no-sound` | без звука (запоминается) |

Настройки хранятся в `~/.config/desktop-goose/config.ini`. Свои мемы (png/jpg/gif/webp) кладите в `~/.config/desktop-goose/memes/`.

## Замечания

- Нужен сеанс X11. Под Wayland гусь сам запускается через XWayland, но переносить курсор там не сможет.
- Без композитора гусь всё равно рисуется аккуратно: окно обрезается по силуэту (XShape), и клики мимо гуся проходят в окна под ним.
- На больших панелях (4K) гусь автоматически увеличивается.
