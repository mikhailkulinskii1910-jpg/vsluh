# Велокарта

Веб-приложение для велосипедиста: карта с офлайн-картами России, маршруты по велодорогам, запись и просмотр пройденных поездок, а также лобби с гонками и погонями для нескольких игроков.

Работает в браузере телефона (Android/iOS, Chrome/Safari) и устанавливается на экран «Домой» как приложение.

## Что умеет

| Вкладка | Что делает |
|---|---|
| **Карта** | Ваша позиция с направлением движения, скорость, заряд телефона, запись поездки (в фоне — пока экран включён). |
| **Маршрут** | Точки ставятся нажатием на карту. Маршрут строится по велодорогам (BRouter), показывает длину, время и подъём. Маршрут можно сохранить, открыть, выгрузить в GPX. «Старт от меня» начинает маршрут с текущей позиции. |
| **Поездки** | Все записанные поездки: длина, время, средняя и максимальная скорость. Показ на карте, экспорт GPX, удаление. |
| **Офлайн** | Скачивание карт выбранной области и диапазона зума в кэш. Пакеты «Москва и область», «Санкт-Петербург и область», «Вся Россия (обзор)» или текущий вид на карте. Список пакетов и удаление. |
| **Лобби** | Создание лобби с 6-символьным кодом, вход по коду, список игроков с их скоростью, зарядом, расстоянием и направлением. Режимы **гонка** и **погоня**. |

### Гонка

Хост выбирает маршрут (сохранённый или текущий из вкладки «Маршрут») и запускает игру. Через 10 секунд старт. Игрок финиширует, когда доехал до конца маршрута (радиус финиша 30 м). Первый финишировавший получает место 1. Остальным даётся окно (по умолчанию 2 минуты, настраивается хостом), потом гонка заканчивается. Есть общий лимит времени.

### Погоня

Хост отмечает догоняющих; остальные — беглецы. Догоняющий побеждает, если подъехал к беглецу ближе **2 м** и держит это **2 секунды** подряд. Если расстояние стало больше 2 м — отсчёт сбрасывается. Если время вышло (по умолчанию 20 минут), побеждают беглецы. Порог расстояния и время контакта хост может поменять.

## Структура

```
velo/
  index.html, style.css, manifest.webmanifest, sw.js   — приложение и офлайн-оболочка
  vendor/leaflet.js|css                                  — Leaflet 1.9.4 (в репозитории, без CDN)
  js/geo.js       — геометрия: расстояние, проекция на маршрут, тайлы (общая для клиента и сервера)
  js/store.js     — IndexedDB (поездки, маршруты, пакеты) и настройки
  js/net.js       — клиент лобби: WebSocket, переподключение, возврат в лобби по токену
  js/offline.js   — скачивание и удаление офлайн-пакетов тайлов
  js/app.js       — карта, GPS, запись, маршруты, вкладки
  js/lobby.js     — интерфейс лобби, гонка и погоня на экране
  server/         — сервер лобби (Node.js + ws): раздаёт папку velo/ и WebSocket /ws
    game.js       — правила гонки и погони (без сети, покрыто тестами)
    server.js     — HTTP и WebSocket
    test/         — тесты правил: npm test
```

## Запуск

### Локально (всё вместе)

```bash
cd velo/server
npm install
npm start            # http://localhost:8080
```

Откройте адрес в браузере (на телефоне — по адресу компьютера в локальной сети, но тогда нужен HTTPS для GPS и service worker; проще задеплоить сервер, см. ниже).

Тесты правил гонки и погони:

```bash
cd velo/server && npm test
```

### На хостинге

Сервер — обычное Node.js-приложение (порт берётся из переменной `PORT`), для работы WebSocket нужен HTTPS (`wss://`), иначе GPS и service worker в браузере не заработают. Подходят Render, Fly.io, Railway или свой VPS с nginx. Пример команды запуска: `node velo/server/server.js`, зависимость — `ws`.

Когда приложение открыто с того же адреса, что и сервер, адрес лобби подставляется автоматически (`wss://<хост>/ws`).

Приложение можно опубликовать и отдельно (например, на GitHub Pages — папка `velo/`), тогда в поле «Сервер лобби» вводится адрес WebSocket вашего сервера, например `wss://velo.example.com/ws`.

## Как устроено

- **Позиции игроков** уходят на сервер примерно раз в секунду (в игре — каждые 0.5 с). Сервер рассылает состояние комнаты не чаще раза в секунду, плюс сразу при событиях (старт, финиш, поимка).
- **Правила гонки и погони** считает сервер (`server/game.js`), а не телефоны: прогресс по маршруту, финиш, контакт догоняющего с беглецом. Клиент только показывает результат.
- **Офлайн-карты** — это тайлы OpenStreetMap, сохранённые в Cache API. Service worker отдаёт их из кэша, когда сети нет. Маршрут, сохранённый или показанный ранее, тоже доступен офлайн, так как хранится целиком.
- **Лобби** живёт в памяти сервера: если сервер перезапустится, комнаты пропадут. Если телефон потерял сеть, он возвращается в лобби автоматически по токену (в пределах вкладки).

## Ограничения, о которых стоит знать

- **Точность GPS.** Телефонный GPS обычно даёт погрешность 3–10 м. Порог 2 м для погони по GPS на практике почти недостижим: два телефона на одном месте показывают разные точки. Сервер учитывает точность: если у любого из двух игроков погрешность больше `maxAccM` (по умолчанию 15 м), контакт не засчитывается. Для честной погони с порогом в 2 м нужны RTK-GPS или хотя бы игровой режим с большим порогом; порог меняется хостом.
- **Офлайн-карты и правила OSM.** Политика tile.openstreetmap.org запрещает массовую загрузку тайлов. Приложение ограничивает пакет 6000 тайлами и грузит в 4 потока, но для серьёзного офлайн-использования лучше указать в настройках («Офлайн» → «Адреса карт и маршрутов») адрес своего тайлового сервера или провайдера, который разрешает кэширование.
- **Маршруты** строятся онлайн через публичный BRouter (`brouter.de`). Офлайн-маршрутизации в браузере нет: для неё нужны графы дорог на телефоне (сотни мегабайт на регион). Адрес сервера маршрутов можно заменить на свой экземпляр BRouter.
- **iPhone и фон.** Safari останавливает страницу, когда экран заблокирован или приложение свёрнуто, поэтому запись поездки и обмен позициями при блокировке экрана могут прерываться. Android в установленном приложении продолжает работать дольше. Запрет на гашение экрана (Wake Lock) включается во время записи и в лобби, где браузер его поддерживает.
- **Заряд телефона** читается через Battery API: в Chrome/Android он есть, в Safari на iPhone — нет (тогда показывается «—»).
- **Направление движения** берётся из GPS, а при низкой скорости — из последних позиций; на стоянке стрелка не обновляется.
