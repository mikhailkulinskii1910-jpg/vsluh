# Сборки «Велокарты»

- `velokarta-debug.apk` — Android-приложение (Capacitor), подписано отладочным ключом. Подходит для установки вручную (Настройки → Безопасность → установка из неизвестных источников). Для публикации в RuStore нужна релизная сборка с собственным ключом: `cd velo/app && npm run apk:release`.
- Веб-версия: откройте `velo/index.html` через сервер из `velo/server` (см. `velo/README.md`).
