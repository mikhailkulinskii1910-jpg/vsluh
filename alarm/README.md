# Сигнализация (Android)

Приложение с одной кнопкой «ВКЛЮЧИТЬ / ВЫКЛЮЧИТЬ».

Когда сигнализация включена и вы включаете экран телефона:
- появляется красное окно поверх экрана блокировки с полем для пароля;
- зазвучит громкий сигнал на максимальной громкости будильника;
- кнопка «Назад» окно не закрывает.

Пароль: **88006553535**. После правильного ввода сигнал выключается и сигнализация
отключается — чтобы включить её снова, откройте приложение и нажмите «ВКЛЮЧИТЬ».

Сигнализация работает только на вашем собственном телефоне.

## Сборка

Нужны Android Studio (или Android SDK с платформой 35) и JDK 17+.

```
cd alarm
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Установите его на телефон
и разрешите установку из неизвестного источника.

## Что разрешить после установки

- **Уведомления** — приложение спросит при первом запуске.
- **Показ полноэкранных уведомлений** (Android 14+): Настройки → Приложения → Сигнализация →
  Дополнительно → «Полноэкранные уведомления» (или «Показ поверх других приложений»).
- Отключите оптимизацию батареи для приложения, чтобы система не останавливала службу.

## Ограничения

- Обычное приложение не может полностью запретить кнопку «Домой» и выключение телефона.
  Окно с паролем надёжно перекрывает экран и не закрывается «Назад», но не блокирует
  системные действия. Полная блокировка возможна только при работе как «владелец устройства».
- Окно поверх экрана блокировки появляется, но для входа в телефон по-прежнему нужен
  обычный PIN/отпечаток; после ввода пароля сигнализации он не снимается.
- Звук берётся из стандартного рингтона будильника (отдельный файл не добавлен).
- Ввод пароля работает только при запущенной службе; после перезагрузки служба
  запускается сама, если сигнализация была включена.
