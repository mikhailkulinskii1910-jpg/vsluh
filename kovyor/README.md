# Kovyor — ковёр на рабочем столе

При запуске на рабочий стол падает настоящий (физический) ковёр. Его можно таскать, класть на папки и ярлыки, загибать углы, складывать пополам и комкать — это ткань из ~1400 частиц с гравитацией, трением о стол и жёсткостью на изгиб. Слои ковра не проходят друг сквозь друга (столкновения точка–треугольник с памятью стороны), а ткань почти не тянется даже при резких рывках (ограничители растяжения от точки захвата). Сверху ковёр освещён лампой, отбрасывает мягкую тень, а при загибе видна изнанка.

Окно программы прозрачное и пропускает клики везде, кроме самого ковра, поэтому папки и ярлыки вокруг остаются кликабельными.

## Управление

| Действие | Что происходит |
|---|---|
| Тянуть ЛКМ | хватает ковёр за точку под курсором и приподнимает её — остальное тянется следом, складывается, сползает |
| Колесо мыши во время перетаскивания | выше / ниже поднять край |
| Отпустить на ходу | ковёр «бросается» по инерции |
| Двойной щелчок | встряхнуть |
| Удерживать Esc ~3 секунды (курсор над ковром или ковёр в фокусе) | убрать ковёр (закрыть программу) |
| ПКМ по ковру или значок в трее | меню: расстелить ровно, встряхнуть, скомкать, вернуть в центр, размер, поверх всех окон, автозапуск, выход |

Положение ковра запоминается между запусками.

## Скачать (Windows)

- **[Kovyor-Setup.exe](https://github.com/mikhailkulinskii1910-jpg/vsluh/raw/ccr-08dbd7f4-695puj/kovyor/release/Kovyor-Setup.exe)** — установщик: ставится за пару секунд, создаёт ярлык «Ковёр» и дальше запускается быстро.
- [Kovyor-portable.exe](https://github.com/mikhailkulinskii1910-jpg/vsluh/raw/ccr-08dbd7f4-695puj/kovyor/release/Kovyor-portable.exe) — без установки, но при каждом запуске сначала распаковывается (несколько секунд).

Файлы собирает GitHub Actions на Windows при каждом изменении папки `kovyor/`.

## Запуск из исходников

```bash
cd kovyor
npm install
npm start
```

## Сборка .exe для Windows

```bash
npm run dist:win     # dist/Kovyor-Setup.exe и dist/Kovyor-portable.exe
```

То же самое делает GitHub Actions (`.github/workflows/kovyor.yml`) при каждом изменении папки `kovyor/`: готовые `.exe` лежат в артефакте **kovyor-windows** на странице запуска. Также есть `npm run dist:mac` и `npm run dist:linux` (на Linux нужен композитный менеджер окон для прозрачности).

## Устройство

- `main.js` — прозрачное окно на всю рабочую область, трей, меню; опрашивает курсор и включает «сквозные» клики, когда курсор не над ковром.
- `renderer.js` — физика (Verlet + позиционные ограничения: растяжение, сдвиг, изгиб; трение покоя и скольжения; самостолкновения через сетку) и отрисовка на WebGL2 (освещение по нормалям, изнанка, размытая тень).
- `assets/carpet.png` — текстура ковра (фон вокруг бахромы вырезан в прозрачность).
