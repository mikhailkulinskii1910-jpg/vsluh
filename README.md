# Половозрастные пирамиды

HTML-презентация к уроку географии (15 слайдов, анимации, интерактивные пирамиды России 1946, 1970 и 2025 годов).

**Скачать:** [polovozrastnye-piramidy.html](https://github.com/mikhailkulinskii1910-jpg/vsluh/raw/presentation/polovozrastnye-piramidy.html)

Файл работает без интернета: откройте его в любом браузере. Управление — стрелки на клавиатуре, свайп или кнопки внизу; F — полный экран.
